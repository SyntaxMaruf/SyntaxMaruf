Contribution Snake চালু করতে:
১) Repository → Settings → Actions → General খুলুন।
২) Workflow permissions-এ Read and write permissions নির্বাচন করে Save করুন।
৩) Actions ট্যাবে যান।
৪) Generate Contribution Snake workflow নির্বাচন করে Run workflow চাপুন।
৫) workflow সফল হলে README-তে snake দেখা যাবে। GitHub Actions চালাতে কয়েক মিনিট লাগতে পারে।
