# সেটআপ গাইড (এই ফাইলটা GitHub-এ আপলোড করার দরকার নেই)

1. Repo SyntaxMaruf/SyntaxMaruf খুলুন > Add file > Upload files।
2. README.md আর assets ফোল্ডার টেনে ছাড়ুন > Commit changes।
3. .github/workflows/snake.yml: Add file > Create new file > নামে `.github/workflows/snake.yml` লিখুন > এই zip-এর snake.yml-এর লেখা পেস্ট করুন > Commit।
4. Settings > Actions > General > Workflow permissions > Read and write permissions > Save।
5. Actions ট্যাব > Generate Contribution Snake > Run workflow। সবুজ টিক আসলে snake দেখা যাবে।
6. README.md-তে Facebook/Email লাইনের comment তুলে নিজের লিংক বসান।
